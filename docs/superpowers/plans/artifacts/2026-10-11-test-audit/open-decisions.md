# Open rule decisions (merged)

Every open rule decision from the six slice files of the [test-case inventory](README.md), renumbered globally `R01` to `R32`. The slices numbered their decisions independently (`OD-1`, `OD1`, `D-01`), so the same id meant different decisions in different files; this file replaces those local ids. Ids are positional case ids from [cases.md](cases.md) (commit `813ed82c`).

## How to read it

- **status**: `open` until the controller fills the `controller ruling` column; `resolved` rows already carry the controller's ruling.
- **category**:
  - `source-conflict`: two documented sources disagree (for example a CHANGELOG entry against a design doc).
  - `undocumented`: only the code defines the behavior; no project document states the expectation.
  - `known-defect`: a spec or CHANGELOG already calls the current behavior a bug.
  - `product-choice`: needs an owner decision, with no documentation either way.
- **sources found** quote at most 12 words each. Paths are repo-relative; `CHANGELOG` versions are the version block that holds the entry.
- A case that is blocked by a decision keeps its slice disposition; [worklist.md](worklist.md) shows the `R` ids next to each affected case.
